## Release notes
This release freezes the code, derived tables, data manifests, tests and manuscript-facing figures supporting “Spatial robustness and environmental side information in regenerative positional memory”. It includes exhaustive checks for the connected-lesion theory, training-frozen axolotl cross-series analyses, and an end-to-end fish-level remote-dorsal negative control for killifish. Third-party source data are not redistributed; exact GEO accessions, filenames and SHA-256 hashes are provided. This release is intended to be archived with Zenodo and cited by DOI in the manuscript.
